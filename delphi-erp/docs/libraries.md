# Bibliotecas Recomendadas

## Base

- FireDAC
  Acesso a banco principal.
- PostgreSQL
  Banco de dados recomendado para a primeira versão.

## UI

- VCL nativa
  Base estável para desktop Windows.
- SVGIconImageList
  Ícones modernos em SVG.
- TMS VCL UI Pack
  Opcional para acelerar UI premium.
- Skia4Delphi
  Opcional para rendering e refinamento visual.

## Relatórios

- FastReport VCL
  Mais indicado para produto comercial.
- FortesReport
  Alternativa open source.

## REST e integração

- REST.Client
  Consumo simples de APIs REST.
- NetHTTPClient
  Mais controle para integrações específicas.

## Fiscal e comunicação

- ACBr
  Recomendado para NF-e, NFC-e, boletos e integrações brasileiras.
- Indy
  Pode ser útil para SMTP e integrações legadas.

## Padrão sugerido

- `VCL + FireDAC + PostgreSQL + FastReport + ACBr + SVGIconImageList`
